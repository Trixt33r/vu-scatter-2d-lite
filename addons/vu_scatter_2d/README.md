# Vu Scatter 2D

Brush-paint props onto 2D levels in the Godot 4 editor (4.4 to 4.7).

Quick start (works in an empty project):
1. Project > Project Settings > Plugins: tick **Vu Scatter 2D**. The **Vu Scatter** panel opens on the right with a short Getting started list.
2. Click **+ Add scatter layer**. With no scene open, it makes a 2D scene (`level.tscn`) for you.
3. Click **Use example props** (trees, bushes, rocks that come with the plugin), or drag your own images in.
4. Drag over the 2D view to paint. Shift + drag erases, Ctrl+Z undoes.

The full guide with pictures: click the **?** button at the top of the Vu Scatter panel, or open `USER_GUIDE.pdf` or `USER_GUIDE.html` in this folder (any web browser opens them). The same guide is in `USER_GUIDE.md` as plain text.
